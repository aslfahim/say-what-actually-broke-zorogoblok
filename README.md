One line of software error copy that tells the brutal truth about the
failure — and makes the user laugh. The auth bug: your password was
right, but the server lost your session somewhere between the database
and the login button.

## Entry

> Your password was right. We lost it. Somewhere between the database and the login button, our server misplaced your session — please sign in again while we check behind the couch cushions.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (Python standard library
only, no dependencies).
